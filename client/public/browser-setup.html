A browser that runs
on your computer.

Give Nalu its own browser to work in. Watch what it does, take control to sign in, and let it continue when you’re ready.

Start the companion

For Mac and Linux, install Node.js 22 or newer and Google Chrome or Microsoft Edge. Then paste this command into Terminal:

curl -fsSL https://n4lu.com/install-browser.sh | sh

  1. Keep the Terminal window open. It will show your private connection code.
  2. Sign in to Nalu and open Browser from the workspace.
  3. Enter the connection code and allow local-network access if your browser asks.
  4. Open a website, sign in directly, and tell Nalu what to do.
Open Nalu

To start it again later, run ~/.nalu/browser-device/start. Press Control-C in Terminal to stop the companion.

Your accounts stay separate

Each Nalu account and agent gets its own browser profile and virtual mouse. Website logins stay on this computer. Nalu’s online AI receives the page content and screenshots it needs to work.

Use Take control whenever you need to help. Sign in or answer Nalu’s question, then choose Continue task. Enter passwords and verification codes in the website itself, never in chat.

The number of browsers that can run at once depends on the computer. Additional tasks wait for a free slot; close an agent browser when you’re finished with it.

Using Nalu Desktop 0.1.40 or newer

If your installed build includes Browser connection, choose Nalu → Browser connection and copy its code instead. Keep Nalu Desktop running. Do not start both companions at once.
